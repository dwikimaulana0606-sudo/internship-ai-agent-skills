# Internship AI Agent Skills

Kumpulan lima Agent Skills untuk membantu pekerjaan repetitif mahasiswa magang:
1. Administrasi perkantoran dinas pemerintahan daerah
2. Registrasi dan anamnesa administratif klinik
3. Digital marketing agency
4. HRD perusahaan sawit
5. Administrasi kredit bank

## Isi repository
Setiap folder `skills/<nama-skill>/` memiliki `SKILL.md` berisi metadata, alur kerja, kemampuan, aturan output, batasan, dan contoh prompt.

## Cara menggunakan
1. Pilih folder skill sesuai bidang.
2. Buka dan baca `SKILL.md`.
3. Gunakan pada AI agent/assistant yang mendukung format Agent Skills atau salin instruksinya sebagai prompt sistem.
4. Berikan instruksi dan data yang diperlukan, dengan data sensitif dianonimkan.
5. Periksa hasil dan minta pegawai/pembimbing yang berwenang menyetujui sebelum dipakai secara resmi.

## Batasan
Skills ini membantu menyusun dan memeriksa draft. Tidak menggantikan keputusan pegawai, dokter, HR, atau pejabat kredit. Jangan memasukkan data pribadi/rahasia ke AI yang tidak disetujui institusi. Untuk klinik dan bank, gunakan data fiktif atau anonim saat demonstrasi.

## Contoh penggunaan
Prompt:
> Gunakan skill `digital-marketing-agency`. Buat kalender konten Instagram 5 hari berdasarkan brief berikut...

Prompt:
> Gunakan skill `government-office-admin`. Ringkas surat yang saya berikan dan tandai informasi yang belum tersedia.
